# Asset licence ledger

Required by PRD section 6.3 (every shipped asset listed with a commercial-compatible licence
before any paid release). Written from what is visible in the repository; anything that could
not be confirmed from files in the repo is marked **unverified**. URLs and download dates are
**not recorded in repo** unless a row says otherwise: add them when each source is re-checked.

Status key: OK = licence text present in repo and permits commercial use. UNVERIFIED = no licence
file in repo, confirm before any paid release. BLOCKED = licence forbids commercial use.

## Rules going forward

1. Add a row here in the same commit as any new asset file. Record author, licence, source URL and download date.
2. Prefer CC0, then CC-BY. Keep a copy of the licence text next to the pack.
3. Never derive new art from the Sprout Lands free pack. Never add Mana Seed while AI-assisted tooling is used on the project.
4. Files in `graphics/placeholder/` are generated; their sources are named per asset in `tools/make_placeholder_art.sh`.
